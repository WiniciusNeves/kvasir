# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ([em português](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)).

## Em resumo

Queremos que participar do Kvasir seja uma experiência sem assédio para todas as pessoas, independentemente de idade, corpo, deficiência, etnia, identidade ou expressão de gênero, nível de experiência, nacionalidade, aparência, raça, religião ou orientação sexual.

**Esperamos:** respeito, empatia, críticas construtivas sobre o código (não sobre a pessoa), aceitar feedback e assumir os próprios erros.

**Não aceitamos:** assédio, linguagem ou imagens sexualizadas, ataques pessoais ou políticos, trolling, publicar informação privada de alguém sem permissão, ou qualquer conduta inadequada num ambiente profissional.

## Aplicação

Comportamentos inaceitáveis podem ser reportados aos mantenedores pelo reporte privado do GitHub (aba **Security** → **Report a vulnerability**, informando que é sobre conduta) ou por mensagem direta ao mantenedor no GitHub ([@WiniciusNeves](https://github.com/WiniciusNeves)). Todo relato é tratado com sigilo.

Os mantenedores podem remover comentários, commits, issues e PRs que violem este código, e advertir, suspender ou banir quem o descumprir, conforme as diretrizes de aplicação do Contributor Covenant.
